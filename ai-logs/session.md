# AI Logs

This folder contains exported chat logs from Amazon Q Developer used during this project.

Prompts used:
1. Read brief and generate full project scaffold (Node/Express backend, React frontend, PostgreSQL)
2. Generate DB schema migrations and seed SQL
3. Generate transactional release/complete/cancel route logic with FOR UPDATE row locking
4. Generate React pages: StockPage, OrdersPage, NewOrderPage, OrderDetailPage
5. Generate Docker Compose and Dockerfiles
6. Generate README and BUILD_LOG
